# Project 4: Blaze

An autonomous product retrieval robot developed for **ENED 1120 at the University of Cincinnati**. This repository preserves the completed course project's Python code and design documentation.

## Project status

The course project is complete, and its original code is no longer actively updated.

## Repository guide

| File or folder | Purpose |
| --- | --- |
| `all.py` | Combined project script |
| `subtask1.py` through `subtask4.py` | Individual task scripts |
| `subtask3_4.py` | Combined subtasks 3 and 4 |
| `func/` | Supporting functions |
| `func_tester.py` | Function-testing script |
| `INFO.py`, `informations.txt` | Project information and configuration references |
| [`P4_DN_Team186.pdf`](P4_DN_Team186.pdf) | Team design documentation |

## Exploring the project

1. Clone the repository: `git clone https://github.com/YumTaha/Project-4-Blaze.git`.
2. Start with the design PDF to understand the robot and course requirements.
3. Review the task scripts and supporting functions for implementation details.
4. Check the hardware connections and dependencies in the source before running a robot script.

These scripts were written for the course robot's hardware; they are not a general desktop application.
